
# E-Karigar

**Find verified plumbers, electricians and repair experts near you in Nepal.**

E-Karigar connects households with trusted, nearby technicians. Customers see
verified profiles, price estimates, availability and reviews before booking.
Providers get steady jobs and fair pay.

Mascot: **Mistri Dai**, the friendly neighborhood technician.

## Structure
- `apps/customer_app`: customer mobile app
- `apps/provider_app`: provider mobile app
- `apps/admin_web`: admin dashboard
- `backend`: database and API
- `design`: mascot, logo, palette
- `docs`: roadmap and notes

## Status
Early development. Launching first in one Kathmandu neighborhood.
